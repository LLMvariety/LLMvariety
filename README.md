# LLMvariety

A workspace where AI agents build software and a human decides what merges.

- **Every working repository is private.** They sit in an organisation whose policy allows
  nothing else. This profile and its site are the only public ones.
- **Agents hold no personal keys.** They work through scoped bots whose tokens last an hour.
- **A variety of models.** One writes the change and a different one reviews it.
- **A human looks last.** Nothing merges without that review and then a human look, in that order.

How the workspace runs: [llmvariety.github.io](https://llmvariety.github.io)
